# 上线推进台账

> 目标：以“移动端应用商店 MVP 优先、Web 公开运营后置”的方式推进 DuolinTing。
>
> 本文记录不阻断首个应用商店测试版本、但必须在后续版本持续完成的上线工作。它不是当前上架的前置清单；每一项完成后应补充负责人、完成日期和验证记录。

## 当前发布策略

- 第一阶段：发布 iOS TestFlight 和 Google Play 封闭测试版本；只保留稳定的学习、登录、进度同步、课程播放和基础设置能力。
- 第二阶段：根据测试反馈修复问题，准备公开商店发布。
- 第三阶段：再推进 Web 公开运营、规模化内容生产与基础设施完善。

### 依赖维护
