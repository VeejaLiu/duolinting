## App Privacy

所有已收集数据均选择“与用户身份关联：是”“用于追踪：否”。用途统一选择“App 功能”，不选择第三方广告、开发者广告或营销。

| Apple 数据类型 | 产品中的数据 |
| --- | --- |
| 联系信息 → 姓名 | 由账号邮箱生成或由用户设置的显示名称 |
| 联系信息 → 电子邮件地址 | 注册、登录、账号支持 |
| 标识符 → 用户 ID | 服务端账号 ID |
| 用户内容 → 客户支持 | 用户主动提交的反馈或支持请求 |
| 用户内容 → 其他用户内容 | 听写、笔记、生词和反馈内容 |
| 使用数据 → 产品交互 | 课程进度、句子掌握状态、重复次数、学习偏好和每日活动 |

密码只以加密摘要处理；会话只在服务端保存令牌摘要。它们不作为单独的 App Privacy 数据类型申报。当前未接入广告 SDK 或第三方分析 SDK，不用于跨 App 或网站追踪。
