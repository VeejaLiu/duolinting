# DuolinTing 官网一期：信息架构、文案与视觉方向

> 目标：用一个清晰、可信、轻量的产品官网，让第一次认识 DuolinTing 的学习者可以立即体验，让 Android 用户能安全下载 APK，并让教师、内容创作者和自托管用户理解产品能力与开源入口。

## 1. 官网定位与原则

DuolinTing 是独立的开源语言听力学习产品，不是 YouZack 官方产品。官网不替代学习端、管理后台或文档站；它负责介绍产品、引导体验与下载、建立信任，并把用户带到正确的产品入口。

一期遵循五个原则：

1. **一个核心结果。** 首屏只回答“我能不能更好地听懂真实材料”，而不是罗列功能。
2. **先体验，再说明。** “网页立即体验”是首要行动；“下载 Android APK”是同等明显的平台选择，但不与复杂的注册流程绑定。
3. **产品真实可见。** 使用真实学习端、移动端与制课工作台截图；不使用与产品无关的库存人物图，也不虚构用户数、评分、合作伙伴或学习效果。
4. **APK 下载可验证。** APK 只从官方域名的 HTTPS 地址分发；下载页清楚显示版本、发布日期、文件大小、SHA-256、更新说明和包名。
5. **中英内容等价。** 中文与英文从同一消息架构生成；一期只上线 `zh-CN` 和 `en-US`，但 URL、页面标题和站点地图为后续语言扩展预留结构。

## 5. 下载页内容结构

### `/download`

1. 标题：选择适合你的方式开始练习。
2. 平台卡片：网页（可立即使用）、Android（APK 官方下载）、iOS（准备中，不提供直装 IPA）。
3. 为什么从官网获取 APK：说明只使用官方域名、HTTPS、签名版本和哈希校验。
4. 更新方式：新版本始终在同一下载地址发布；保留历史版本和更新说明。

### `/download/android`

1. Android 产品预览、主要能力、唯一“下载最新版 APK”按钮。
2. 发行信息：`版本号`、`发布日期`、`文件大小`、`包名 com.duolinting.app`、`SHA-256`、`更新说明`。
3. 安装步骤：下载 → 在系统提示中允许本次来源安装 → 安装 → 打开 DuolinTing。
4. 安全提示：Android 或 Play Protect 可能对非商店来源显示提示；只从本页官方域名下载，并对照 SHA-256。不要要求用户关闭系统级安全保护。
5. 更新与旧版本：稳定地址始终指向最新版本；历史版本按版本独立保留，且清楚标记“当前 / 已归档”。
6. 常见问题与支持入口。

### 每次 APK 发布前必须填入的发布清单

| 字段 | 来源 / 规则 |
| --- | --- |
| 显示版本 | `mobile-app/app.json` 的 `expo.version` |
| Android 构建号 | `android.versionCode`；新版必须递增 |
| 文件名与稳定地址 | 版本化文件名 + `/download/android/latest` 这类稳定入口 |
| 文件大小与 SHA-256 | 对最终上传的 APK 重新计算，禁止手填或复用旧值 |
| 更新说明 | 只记录已验证并发布的变化 |
| 签名信息 | 保留发布签名的证书指纹，供需要验证来源的用户查验 |
| 可用性核验 | 真机安装、冷启动、登录、课程播放、进度保存；同时检查下载链接与哈希 |

APK 不能提交到 Git 仓库，也不能随着官网静态资源一起打包。二进制文件应放在独立的发布存储/CDN；官网下载页只引用经 HTTPS 分发的文件与发行清单。

## 8. 视觉方向与交付要求

### 品牌语气

学习端可以明亮、有鼓励感；官网应更安静、清楚、可信。视觉基调是“清晨的学习空间”：大面积留白、蓝色建立行动和可信度、暖黄只用于进度和奖励性的微小强调。避免重游戏化、虚假的数据面板、自动播放视频和过度漂浮动画。

### 视觉系统

| 元素 | 方向 |
| --- | --- |
| 主色 | `#1cb0f6`（Duolingo blue）；按钮、链接、焦点与正常互动元素 hover 时的边框使用此色。 |
| 深色文字 | 近深蓝黑，保障阅读对比度。 |
| 背景 | 偏白蓝的柔和底色与纯白内容表面；使用浅色渐变表达声音扩散，不依赖复杂插画。 |
| 字体 | 中文：系统无衬线优先；英文：现代 humanist sans。标题粗而不夸张，正文保持舒适行距。 |
| 圆角与阴影 | 中等圆角、低对比阴影；只有产品预览与重点行动卡片使用表面层级。 |
| 图像 | 优先用真实产品截图，统一放在手机 / 浏览器框内，并附真实说明文字。 |
| 动效 | 只为解释播放、时间轴或状态变化服务；支持 `prefers-reduced-motion`，禁止自动播放有声内容。 |

### 响应式与无障碍
